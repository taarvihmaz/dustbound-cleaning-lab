# Start here

Open **Dustbound.html** to play the offline campaign. Choose a cleaner, press **Start campaign**, then select a tile. Clear every patch to open the next level.

Open **game/lab.html** to run the 5 × 5 course experiment in a browser. For the Python version, follow the Streamlit instructions in the README.

The full package includes a technical report in Word and PDF, an eight-slide presentation, the video, test results, and the team and AI statements. Start with the project README for the links.
