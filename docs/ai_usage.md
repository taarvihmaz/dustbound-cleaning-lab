# AI usage declaration

The user chose Topic 19, set the scope and numerical assumptions, and requested the interface, course materials and game features. The user also reported that clicking bare floor could make dirt appear and asked for a level to end only after its last patch was removed.

ChatGPT helped explore ideas and plan the project. OpenAI Codex wrote much of the Python and JavaScript code, built the interface and artwork, wrote and ran automated tests, and prepared the report, slides, README and demo video. Codex used the project code and recorded results to describe what the robot does.

The running game uses programmed rules for search, probability and action choice. It needs no AI account or model service to play. The sensor rates are teaching assumptions. The tests use a simulated floor.
